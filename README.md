# 数桥 DBridge · 数据库同步工具

> 一个"给不会写配置文件的人用"的图形化数据库同步工具。
> 选表 → 点按钮 → 数据同步过去，之后按频率自动跑。

数桥（DBridge）把数据库之间的数据搬运做成了「点点鼠标就能完成」的事：不需要手写 SQL、不需要懂
SeaTunnel / 配置文件的语法，填好连接、勾选要同步的表和字段，剩下的交给程序。它会先体检、再试跑、
最后才正式同步，全程用"人话"告诉你每一步发生了什么。

本仓库用于**项目介绍与公开信息展示**，不含完整源码。核心实现为闭源，这里只放少量不涉及核心逻辑的
通用示例代码。

---

## 产品能做什么

- **图形化数据源管理**：MySQL / SQL Server / PostgreSQL 三种数据库，填主机、端口、账号、密码即可，
  测试连接一键通过。
- **选表选字段**：不用手写 SQL 或配置文件，勾选要同步的表和字段就行。
- **自动建目标表**：目标库没有对应表时自动建表，字段类型自动映射。
- **字段自动匹配**：源表与目标表字段按同名、别名、中文注释等 9 级打分自动对应，省去手工对齐。
- **定时调度**：按 cron 频率自动跑，支持全量 / 增量（水位线）同步。
- **增量水位**：按时间戳 / 自增主键推进，只同步新增和变更的数据，不重复、不漏数。
- **运行历史与日志**：每次运行留痕，日志可按错误过滤、可下载。
- **试跑校验**：先读几行到临时表回读校验，确认无误再正式同步。
- **一键换驱动**：按目标库实际版本推荐并替换 JDBC 驱动，不用自己挑版本。

## 核心特点

### 三层递进，保证不会写坏数据

```
体检（只读）  →  试跑（读几行写临时表）  →  正式同步（写正式表）
   随时点          正式表零改动                前置体检不过直接拒绝
```

1. **体检**：15+ 项检查（连接 / 权限 / 类型 / 主键冲突 / 非空列等），按 BLOCK / WARN / OK 分级。
2. **试跑**：只读几行写进临时表，回读校验无误后自动删表，绝不碰正式表、绝不推进水位。
3. **正式同步**：体检有 BLOCK 直接拒绝，带着已知错误去写数据这种事从一开始就不允许发生。

### 报错说人话

连接失败、权限不足、类型不匹配、主键冲突等 20+ 类异常，都会被翻译成「原因 + 该干什么」，而不是
甩给你一段英文堆栈。

### 增量不重复、不漏数

水位取「运行开始时的最大值」，查询起点再回退，靠 upsert 吸收重叠；水位精度到毫秒，减少同秒重复读。
毫秒时间戳、数字型主键等 6 种水位类型分别处理，不会出现"数字被加了引号导致排序错乱"这类隐蔽问题。

### 断网也能用

数据同步在你的内网/本机跑，不依赖外网。JDBC 驱动、Java 环境都内置或可离线，常见版本驱动已预置。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Java 11 · Spring Boot |
| 数据访问 | JDBC（MySQL / SQL Server / PostgreSQL 驱动） |
| 存储 | H2（嵌入式文件库） |
| 前端 | 原生 HTML / CSS / JS（单页，无框架） |
| 同步引擎 | Apache SeaTunnel |

## 部署方法

分两种包，功能完全一致，只差 Java 环境：

| 包 | 大小 | 说明 |
|---|---|---|
| **lite 版** | 约 40 MB | 不含 Java。解压后先跑「环境检测.bat」，自动下载 JDK 与数据库驱动（需能上外网） |
| **full 版** | 约 95 MB | 内置 Java 11，解压即用，适合内网、不能上外网的机器 |

### 三步装起来

1. **解压**：把压缩包整个解压到硬盘（例如 `D:\DBridge`）。不要放 `C:\Program Files`，也不要在压缩包
   里直接双击运行——那里没有写权限。路径里尽量不要有中文。
2. **检测环境**：双击「环境检测.bat」，逐项检查并给出结论（`OK` / `注意` / `失败`）。缺 Java 自动下载、
   缺驱动自动补齐，全部通过后生成环境配置。
3. **启动**：双击「启动.bat」，等约 10 秒，浏览器打开 `http://localhost:27301`。那个黑色窗口就是服务本身，
   关掉即停止服务。

### 首次登录

出厂账号 `admin`，登录后系统会引导修改密码。忘了密码可以用环境变量重置（详见交付说明）。

### 开机自启

给「启动.bat」建快捷方式放进启动文件夹（`Win+R` → `shell:startup`），或用「任务计划程序」创建
「计算机启动时」运行的任务。

### 文件结构

| 文件 / 目录 | 用途 |
|---|---|
| `环境检测.bat` | 检查环境、自动下载 Java 与数据库驱动 |
| `启动.bat` | 启动控制台 |
| `lib\dbridge.jar` | 主程序 |
| `runtime\jdk11\` | 内置 Java 11（lite 版没有，检测时下载） |
| `drivers\` | 数据库驱动（MySQL / PostgreSQL / SQL Server） |
| `data\` | 你的数据、账号等，**备份就拷这个目录** |
| `logs\` | 运行日志，出问题时打包这个目录发给支持方 |
| `work\` | 临时目录，可整个删除，会自动重建 |
