# DBridge · 数据库同步工具（公开说明）

> 一个"给不会写配置文件的人用"的图形化数据库同步工具。
> 选表 → 点按钮 → 数据同步过去，之后按频率自动跑。

本仓库仅用于**项目介绍与公开信息展示**，不含完整源码。
核心实现为闭源，这里只放少量不涉及核心逻辑的通用示例代码。

---

## 它能做什么

- **图形化数据源管理**：MySQL / SQL Server / PostgreSQL 三种数据库，填主机端口账号密码即可，测试连接一键通过。
- **选表选字段**：不用手写 SQL 或配置文件，勾选要同步的表和字段。
- **自动建目标表**：目标库没有对应表时自动建表，字段类型自动映射。
- **定时调度**：按 cron 频率自动跑，支持全量 / 增量（水位线）同步。
- **增量水位**：按时间戳 / 自增主键推进，只同步新增和变更的数据。
- **运行历史与日志**：每次运行留痕，日志可按错误过滤、可下载。
- **试跑校验**：先读几行到临时表回读校验，确认无误再正式同步。

## 设计理念

**三层递进，保证不会写坏数据**：

1. 先试跑（读几行 → 临时表 → 回读校验 → 删表）
2. 预检 15+ 项（连接 / 权限 / 类型 / 主键冲突等，BLOCK / WARN / OK 分级）
3. 正式同步

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Java 11 · Spring Boot |
| 数据访问 | JDBC（MySQL / SQL Server / PostgreSQL 驱动） |
| 存储 | H2（嵌入式文件库） |
| 前端 | 原生 HTML / CSS / JS（单页，无框架） |
| 同步引擎 | Apache SeaTunnel（数据同步底层） |
